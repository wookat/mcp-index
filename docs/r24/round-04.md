## 4. 剩余差距与理由

1. **视觉设计仍微输 Smithery（8.4 vs 8.5）**：其插画吉祥物+编辑感排版构成独有品牌记忆点；我方选择「数据驱动色彩系统」路线（徽标/头像色相哈希），不抄插画路线。要反超需委托原创品牌插画/吉祥物设计（新实体，超出本产线授权，列为后续立项建议）。
2. **detail 页 server tools 清单**（Smithery 有逐工具列表）：需数据管线扩展抓取 tools 元数据，工程量大，R1 起登记为 P2，未在四轮内实施。
3. **方法学**：独立盲评未能执行（组织并发满），比分为负责人保守自评，存在利益相关偏差风险；并发释放后建议补一次独立盲评校准。
